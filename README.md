# Personal-Portfolio-Website

💻 Personal Portfolio Website

A modern and responsive personal portfolio website designed to showcase my skills, projects, education, achievements, and contact information.

This project represents my journey into web development and provides a central place to showcase the projects and technologies I am learning and working with.

🚀 Features

- 👨‍💻 Personal introduction
- 🛠️ Skills and technologies section
- 📂 Projects showcase
- 🎓 Education section
- 🏆 Achievements and activities
- 📞 Contact section
- 📱 Responsive design
- ✨ Clean and modern user interface
- 🔗 Social media and professional profile links

🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive design
- JavaScript – Interactions and functionality
